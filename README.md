# Il Viaggio Arcade

Juego arcade en pixel art para practicar italiano viajando por Italia.

- **Ruta fácil (A2):** Aosta, Genova, Trento, Trieste, Perugia, Ancona.
- **Ruta B1:** Torino, Milano, Venezia, Bologna, Firenze, Roma, Napoli, Palermo.

En cada ciudad: lección con tablas, retos, diálogos, objeto perdido, baúl con postal, sala de juegos, free walking tour guiado y examen del Capotreno para viajar en VIP.

## Instalar en el móvil

1. Abre el enlace del juego en el navegador del móvil.
2. **iPhone (Safari):** botón Compartir → «Añadir a pantalla de inicio».
3. **Android (Chrome):** menú ⋮ → «Instalar aplicación» o «Añadir a pantalla de inicio».

Funciona sin conexión una vez abierto, y el progreso se guarda en cada móvil.
